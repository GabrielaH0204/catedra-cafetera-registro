# Cátedra Cafetera · Registro (prototipo)

Mock de la página de registro de la Cátedra Cafetera: el territorio como aula (Fundación Manuel Mejía).
Proyecto académico del grupo CG-1, Strategy in Action, Pontificia Universidad Javeriana.

La app no procesa pagos ni guarda datos: todo vive en la sesión del navegador.

## Archivos

```
app.py
requirements.txt
.streamlit/config.toml
README.md
```

## Despliegue en Streamlit Community Cloud

1. Sube los archivos a un repositorio público de GitHub, con `config.toml` dentro de una carpeta llamada `.streamlit`.
2. Entra a share.streamlit.io con tu cuenta de GitHub y pulsa **Create app**.
3. Elige el repositorio, la rama `main` y el archivo `app.py`, y pulsa **Deploy**.

Los precios, fechas y cifras salen del modelo financiero del grupo (Analisis_Financiero_FMM_2025.xlsx).
